# GAViT-VPR
Graph Attention-based Lightweight Re-ranking for Visual Place Recognition
Official research implementation for the paper
"Improving Efficiency and Geometric Consistency in Transformer-based Visual Place Recognition".

This repository contains:
- GAViT: GAT-based lightweight re-ranking.
- GeoConsistency: Geometric consistency evaluation of Vision Transformer backbones.
